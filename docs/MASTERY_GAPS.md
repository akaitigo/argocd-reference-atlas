# Mastery Gap

`mastery.yaml`はArgo CDという対象分野を増やすものではなく、既存Coverageを「理解、選択、構築、検証、運用、診断、進化、委任」のOutcomeと14 Surfaceから利用できるか判定する契約です。

## この実装で接続済み

- 8 Outcomeと14 Surfaceを既存4 Target Setへ接続
- Application、Reconciliation、Sync、Diff、Health、Promotion、Secret boundary、Failure、Recoveryの実行Labと合格Evidence
- Authority Lock、Capability／Claim／Proof Graph、Router Skill、静的Eval Corpus
- Apache-2.0、NOTICE、第三者Manifest、決定論的SPDX SBOM、DCO／Security方針

## `complete`を阻止している不足

- Performance／Capacity／CostのBenchmarkと回帰基準
- 対応Kubernetes Version、Source generator、CLI／APIのCompatibility Evidence
- v3.3／v3.4からv3.5.2へのUpgrade／Rollback Migration Lab
- Metric、Log、Trace、Backup、Incident、Capacityを統合した運用Runbook
- 主要TopologyとSync／Secret／Promotion方式のDecision Matrix
- 実モデルによるRouter Skill Eval採点と最低合格率の証拠
- `local`、`container`、`cluster`全Required Profileを閉じるEvidence集合
- Release Artifact、署名、Completion Certificate、人手による権利・商標・Security Review

9 Targetが`covered`になっても、上記Mastery／Operational／Skill／Publication Closureが残るため、`atlas.yaml`は`status: incomplete`を維持します。件数を満たすためのTarget分割や、根拠のない`not-applicable`指定では解消しません。
